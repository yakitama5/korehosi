# packages_designsystem

## 責務 (Responsibilities)

このパッケージは、アプリケーションの UI デザインシステムを担当します。
再利用可能な UI コンポーネント、テーマ、スタイル定義（色、フォントなど）を提供し、アプリ全体で統一されたルック＆フィールを実現します。

主な役割：

- **UI コンポーネント**: ボタン、入力フォーム、カードなどの汎用ウィジェット。
- **テーマ定義**: `ThemeData` やカラーパレット、フォントスタイル。
- **アセット**: アイコンや共通画像のリソース管理。

## 禁止事項 (Constraints)

- **ビジネスロジック**: 複雑なビジネスルールや状態遷移は記述しません（`packages/application` や `apps/app` へ記述）。UIの振る舞い（アニメーション等）に限ります。
- **インフラへの依存**: 通信やDBなどのインフラ実装に依存してはいけません。
- **特定画面の実装**: 特定の画面（Page）そのものを実装するのではなく、画面を構成する部品を提供します。

## 依存関係 (Architecture Dependencies)

- **許可された依存関係**:
  - `packages/core`
  - `packages/domain` (型定義の利用など)
  - `packages/application` (※現状 `pubspec.yaml` に含まれていますが、循環参照や密結合を避けるため、必要な範囲に留めるべきです)
  - Flutter SDK, UI関連パッケージ
- **禁止された依存関係**:
  - `packages/infrastructure/*`
  - `apps/app` (循環参照となるため)
